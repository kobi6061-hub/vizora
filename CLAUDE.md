# Repository layout

- Repo root = the **PROPX** private dashboard (formerly KobiX RealEstate), deployed to Vercel as-is
  (static `index.html` + `login.html`, Edge `middleware.js` auth gate, `api/` login/logout,
  `vercel.json`). No build step; framework preset must stay "Other"/none.
- `vizora-app/` = the earlier VIZORA Next.js product (self-contained; see its own CLAUDE.md).
- `standalone/` = offline/artifact build of the dashboard, generated by
  `scripts/build-standalone.py` from the root `index.html`. It embeds no password/credential (the
  repo is public); the build script refuses one.
- `scripts/` = KobiX tooling (`kobix-dev-server.mjs` local auth simulation, `build-standalone.py`,
  `gov-sync.js` government-data sync CLI).
- `lib/gov/` + `api/gov/` + `data/gov/` + `test/gov.test.js` = the government real-estate
  data layer (provider architecture, normalized transaction schema, snapshots; see `lib/gov/README.md`).
- `lib/geo/` + `api/geo/` + `data/geo/` + `scripts/build-geo-registry.py` + `scripts/geo-audit.js`
  = the national geography registry (every official locality + street, canonical codes, search API,
  coverage audit).
- `test/integrity.test.js` = P0 data-integrity gates over `index.html` and the standalone build (no
  synthetic street layer, generated history, invented medians or sample-size confidence; OFFICIAL only
  with stored provenance; no ranking over non-official values outside the capital section's labelled
  MODEL RANKING; no embedded credential; no approximate `NATIONAL_CURVE`; capital outside surfaces —
  command-bar signal, map layer, gold markers, profile shortcut, insights teaser — stay off via
  `CI_EXTERNAL=false`).
- `test/capital.test.js` = the capital module (`#capital`, `@ci-engine` block run on the real board
  data): equity accounting (value − debt + tax/costs = equity used; used + unused + reserve = capital),
  caps/capacity/pool/minimum data basis, rankings independent of capital size and of the appreciation
  assumption, every return a true IRR from `calcEngine`/`calcIrr`, data basis from `vcOf` (no o-flags),
  every policy rule and assumption editable in the section.
- `test/calculator.test.js` = the deal calculator (`#calc`, `calcEngine`, `calcIrr`): visible,
  independent of the capital model, missing inputs → UNAVAILABLE (never defaulted), no silent
  appreciation.
- `test/sales-metrics.test.js` = the sales-metric truth gates (audit 13.10.2026): the board's new-home sales figure
  (`txShown`) is shown only where `TX_BASIS` writes down its basis — national 2025 total (STATIC) and Tel Aviv (CBS H1-2026
  count × 12 ÷ 6, MODEL, rendered "~N לשנה" with the formula); every other place and any filtered view shows — (the
  research numbers in `LOCATIONS.base.tx` stay capital-MODEL inputs only); RAW · DERIVED · DISPLAY evidence behind "מקור
  הנתון"; observed deals carry their period and date range, are "new" only as far as the source flags it (the register:
  by build year), and fewer than 10 is a small sample; a static statement older than 90 days is marked stale.
- `lib/cbs-sales/` + `scripts/cbs-sales-sync.js` + `.github/workflows/cbs-sales-sync.yml` + `data/cbs-sales/` + `test/cbs-sales.test.js`
  = official new-home sales (audit 13.10.2026): the CBS time-series API (44,10,2,1 new dwellings sold, monthly, 2016→) for the
  country and its 7 districts ONLY — keyed by the CBS code the API returns (5069–5076), never a name; append-only ledger with
  every revision, raw responses per content hash, T3/T6/T12/YTD/prior YTD/pace/momentum (DERIVED, periods named), source-aware
  freshness (CURRENT / EXPECTED_REPORTING_LAG / STALE), national-vs-districts reconciliation; national inventory + months of
  supply. Synced every working day; `data/cbs-sales/` is bot-written. CBS publishes NO machine-readable city series (city figures
  exist only in the media-release PDF "לוח ב": rolling 3-month windows, >150 sales, names not codes) — not ingested; the board's
  country/district rows read the series (`cbsGeo` / `txShown`), every city and neighbourhood shows "—" except the labelled Tel
  Aviv-Yafo transcription (`TX_BASIS`, release 252/2026). Inventory (`invShown`): national from the series, cited figures from
  release 283/2026 (end-July 2026), else "—"; never split by a filter. The capital model reads no sales pace (liquidity, months of
  supply, pressure and leverage are MISSING). `scripts/cbs-sales-discover.js` + `.github/workflows/cbs-sales-discover.yml` =
  read-only discovery (catalogue, series, release PDFs). See `lib/cbs-sales/README.md`.
- `lib/market/` + `scripts/market-sync.js` + `data/market/` + `.github/workflows/market-sync.yml` +
  `test/market.test.js` = the daily official-indicator sync (Bank of Israel rate, CBS new-homes index; optional monthly
  CBS series found by name: construction inputs 200010, CPI 120010, CPI rent component 120460 — a failure there is

  (see `lib/market/README.md`).

  detail on a daily budget + map centroids) normalized per MichrazID with lifecycle from the Authority's status codes
